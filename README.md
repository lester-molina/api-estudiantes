# API de Estudiantes 🎓

API creada con Django y Django REST Framework para gestionar estudiantes.

## ¿Qué hace?
- Listar estudiantes
- Crear estudiantes
- Ver un estudiante
- Actualizar estudiantes
- Eliminar estudiantes

## Tecnologías
- Python
- Django
- Django REST Framework
